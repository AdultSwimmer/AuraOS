Before we begin — one important thing.
Your memory lives in a file called HISTORY.txt

When you finish each session, AuraOS gives you a ↓ Save HISTORY.txt button.

Click it. Save the file somewhere you will find it — your desktop, a folder, a cloud drive.

Next time you open AuraOS, click "Yes — Load my HISTORY.txt" and everything returns: who you are, what you've worked on, every conversation, every exchange.

The AI doesn't hold the memory. You do.
That's not a limitation — that's the design. The file is called HISTORY.txt. Keep it somewhere safe.

Memory & Export

When you're done, click ↓ Save HISTORY.txt and save the file somewhere on your computer.
Next time you open AuraOS, load it at the start — and everything comes back: your identity, context, and the full conversation log from every session.

No account. No server. The memory lives with you.

This session will end. The AI will not remember it.
But you will save the file. And next time, you'll load it.
It will read fresh and arrive at the same place.

That is not a failure. That is the design.
What happens inside a session still matters completely.
